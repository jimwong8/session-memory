## 二、基于前沿优化的完整架构

### 2.1 核心变化：从"提取蒸馏"到"原文存储+元数据过滤"

```
原方案（类 Mem0）：
消息 → LLM 抽取 → 去重 → 蒸馏存储 → 检索
  ↑ 高成本、有信息损失

新方案（类 MemPalace + Letta）：
消息 → 原文存储 → 元数据索引 → 多层检索 → 按需蒸馏
  ↑ 零写入成本、无信息损失、检索后再蒸馏
```

## 三、分阶段实施方案（优化版）

### Phase 1: P0 — 原文存储 + 元数据过滤（1 周）

**核心改变**：停止对每条消息做 LLM 抽取。原文就是记忆。

**检索管线**：
```
Query → BM25 + Vector + KG 并行
       → 元数据过滤（用户/项目/时间窗）
       → RRF 融合
       → 衰减加权（时间 + 频率 + 重要性）
       → Top-K 返回
```

**预期效果**：检索相关性 +20%，写入成本降至零。

---

### Phase 2: P1 — SWR Tagging（Science 2023 启发）

**核心改变**：不是所有记忆都值得巩固。用 SWR（Sharp Wave Ripple）标记重要记忆。

**夜间巩固只处理 importance > 0.7 的记忆**——节省 80%+ 计算。

---

### Phase 3: P2 — Sleep-Time Compute（Letta 2025 启发）

**核心改变**：分离"快速响应"和"深度巩固"。

**Letta 实测效果**：+13-18% 准确率，60% 成本降低。

---

### Phase 4: P3 — SDR 稀疏编码（Nature Comm 2024 启发）

**核心**：用 Sparse Quantized Hopfield Network 替换 dense embedding。

**Nature Comm 2024 证实**：在线持续学习 + 噪声鲁棒 + 联想记忆 SOTA。

---

### Phase 5: P4 — Modern Hopfield 联想检索（NeurIPS 2021 → 2024）

**核心**：给定不完整线索 → attractor dynamics 恢复完整记忆。

**2024 Diffusion = Hopfield 论文**：扩散模型的能量函数 ≡ Modern Hopfield——生成与提取统一。

---

### Phase 6: P5 — 双时态 KG + 主动提取（ProMem 2026）

**双时态（Zep 方式）**：valid_at + transaction_at

**主动提取（ProMem 2026）**：迭代式自提问提取，比一次性摘要更完整。

## 七、最重要的一个决策

**参考 MemPalace 实证结果**：原文存储 + 元数据过滤 > LLM 抽取蒸馏

这意味着：

1. **白天**：只存储原文 + 元数据索引（零计算成本）
2. **夜间**：只用 LLM 做巩固蒸馏（不在关键路径）
3. **检索时**：原文匹配后按需蒸馏（不是预蒸馏）

**不再"提前蒸馏"，而是"按需蒸馏"。** 这是 MemPalace（96.6% Recall@5）击败 Mem0（93.4%）的根本原因。
